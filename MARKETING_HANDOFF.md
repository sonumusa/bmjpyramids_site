# Marketing / SEO Handoff

## Editable SEO Areas

Admin path:

```text
Admin > SEO Tools
```

Marketing team can edit:

- Home meta title/description/keywords
- Shop meta title/description/keywords
- About/contact meta
- Default product/category SEO fallbacks
- Sitemap generation

Product-specific SEO:

```text
Admin > Products > Edit Product > SEO Fields
```

Category-specific SEO:

```text
Admin > Categories > Edit Category > SEO
```

## Technical SEO Already Included

- Clean URLs with `.htaccess`
- Product schema JSON-LD
- Organization schema JSON-LD
- Breadcrumb schema on product pages
- Canonical URLs
- `sitemap.xml` generator
- `robots.txt`
- SEO-friendly image alt fields
- Product/category meta fields
- Mobile responsive Bootstrap layout

## Recommended Launch Checklist

1. Replace placeholder contact details.
2. Replace/add real product photos.
3. Write unique descriptions for top 20 products.
4. Keep product names searchable: brand + type + size/model.
5. Add internal links from category descriptions.
6. Generate sitemap from admin.
7. Submit sitemap to Search Console.
8. Set up Google Analytics / Tag Manager if required.
9. Add testimonials, certifications and partner logos.
10. Add a blog/news module later for long-tail SEO.
